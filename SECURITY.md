# Security

- Store `OPENAI_API_KEY` only as a GitHub Actions repository secret or a server environment secret.
- Do not commit `.env` files, API keys, Supabase service-role keys, client records or private legal documents.
- The standalone test runner accepts only official HTTPS `cylaw.org` judgment URLs.
- Model output remains subject to exact paragraph evidence validation and human review.
- This repository contains no production MyNomos corpus or Supabase configuration.
